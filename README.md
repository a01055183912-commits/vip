# VIP 멤버십 마케팅 랩

교안 「3-5. VIP 멤버십 마케팅」(43장)을 그대로 옮겨 학습 · 실습 · 근거 탐색을 할 수 있게 만든 웹앱입니다.

- **의미의 흐름**: 7단계(이해 → 벤치마크 → 등급 설계 → 혜택·수익성 → 유지·이탈 → 개인화·CX → 균형·실행)와 단계 사이의 연결 논리
- **타임테이블**: 8시간 강의 큐시트, 각 행에서 해당 내용으로 이동
- **케이스 · 계산기**: A백화점 케이스, 등급 설계·LTV·예산 계산기, 이탈률 개선 시뮬레이터
- **개인 학습 공간**: 이름 + 숫자 비밀번호로 입장. 입력 내용은 사람마다 따로, 그 기기 브라우저에만 저장되어 다른 교육생에게 보이지 않음. 백업(.json) 내려받기·불러오기로 다른 기기에서 이어 하기
- **실습 워크시트**: 실습 ①~⑧ + 추가 실습, 자동 저장, 예시답안 보기, 표 형식 복사
- **실습지 내려받기**: 작성한 답이 채워진 실습지를 교안과 같은 레이아웃의 PowerPoint(.pptx)로 내려받기 (한 장 또는 전체, 예시답안 장 선택)
- **근거 찾기**: Google · 네이버 · 다음 · Bing / Google 뉴스 · 네이버 뉴스 · 다음 뉴스 / YouTube / Google Scholar · RISS · DBpia · Google 트렌드, 공식 홈페이지, 교안 내 검색

## 실행
`index.html`을 브라우저로 열면 됩니다. 별도 서버가 필요 없습니다.

## 수정
내용은 `src/data.js`, 화면은 `src/app.html`에 있습니다. 수정 후 `./build.sh`를 실행하면 `index.html`이 다시 만들어집니다.
